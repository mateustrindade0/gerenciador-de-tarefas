# 🚀 Projeto de Estudos em React

Este projeto foi desenvolvido com o objetivo de aprender e praticar os principais conceitos do **React**, explorando a criação de componentes, gerenciamento de estado e construção de interfaces modernas com **Tailwind CSS**.

## 📚 Objetivo

O foco deste projeto é consolidar conhecimentos em React por meio da implementação de funcionalidades comuns encontradas em aplicações reais.

Durante o desenvolvimento foram praticados conceitos como:

* Componentização
* JSX
* Props
* State (`useState`)
* Renderização de listas
* Manipulação de eventos
* Organização de componentes
* Estilização com Tailwind CSS
* Boas práticas de desenvolvimento

## 🛠️ Tecnologias

* React
* JavaScript
* Vite
* Tailwind CSS

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

2. Acesse a pasta do projeto:

```bash
cd <NOME_DO_PROJETO>
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```

O projeto estará disponível em:

```text
http://localhost:5173
```

## 📁 Estrutura do projeto

```text
src/
├── assets/
├── components/
├── App.jsx
└── main.jsx
```

> A estrutura pode variar conforme a evolução do projeto.

## 🎯 Aprendizados

Este projeto permitiu colocar em prática os fundamentos do React e do Tailwind CSS, reforçando conceitos importantes para o desenvolvimento de interfaces modernas, reutilizáveis e responsivas.
